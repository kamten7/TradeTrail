# TradeTrail 实施路线

本路线从可启动骨架逐步交付交易闭环。每阶段结束都运行本阶段的接口测试，并保持商城服务可启动。版本基线：Java 21、Spring Boot 3.5.x、MyBatis-Plus Spring Boot 3 starter、Vue 3。

| 阶段 | 范围 | 验收 |
|---|---|---|
| 1. 基础工程 | Maven 多模块、商城和物流模拟服务、MyBatis-Plus、Flyway、开发数据库、统一错误响应 | 两个服务启动；数据库迁移成功；接口测试通过 |
| 2. 商品与购物车 | 店家商品与初始库存录入、库存调整，用户商品列表和购物车接口，角色隔离 | 商品可上架并浏览；购物车按用户隔离；接口测试通过 |
| 3. 下单与库存 | 服务端核价、订单快照、条件预留、取消回补、幂等与订单查询 | 重复下单返回同单；库存不足拒绝；订单/库存同事务 |
| 4. 模拟支付 | 演示版内部模拟付款与通知去重；后续扩展独立收银台、签名回调和补偿 | 支付成功后订单待发货；重复付款被拒绝 |
| 5. 履约与售后 | 店家发货、独立物流端轨迹推送与重试、用户轨迹、基础售后申请 | 物流签名回调测试通过；轨迹可查；已支付订单可申请售后 |
| 6. 三端界面与交付 | 用户 H5、店家管理台、物流操作页、启动与演示说明 | 从商品发布到付款、发货、轨迹查询的主链路可在浏览器完成 |

当前实现了上述六阶段的基础主链路。`mvn clean package`、两套前端构建和本机端到端冒烟脚本已通过；脚本完成商品发布、下单、付款、发货、物流推送与轨迹查询。后续增强：独立模拟支付回调与支付尝试、超时关单、退款补偿、outbox 恢复、库存并发压测与完整售后状态机。它们仍按 [Plan.md](../Plan.md) 的最终验收目标推进，不把基础演示版本误写为全部完成。
