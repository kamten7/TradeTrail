## 本轮发现并修正的缺陷

- 登录成功重定向与前端请求不匹配；改为明确 JSON 成功/失败响应。
- 页面与 API 同名，直接刷新页面被 Vite 代理送往后端；改为 `/api` 前缀代理。
- MySQL 默认快照隔离下，等待订单锁后重读仍可能看见旧支付通知；统一 READ COMMITTED 与 MyBatis STATEMENT 缓存范围。
- 应用本地时区与数据库 UTC 不一致，正常物流时间被判未来；两服务与数据库统一 UTC。
- `EXCEPTION` 后 `RESUMED` 不能恢复已经派送的物流；保留派送进度并恢复状态。
- 自动确认只读前 100 条已妥投记录，后续可能永远不处理；增加游标分批遍历。
- 退款失败缺少店家可见入口；新增失败列表与重试操作，并用真实页面跑故障演练。
