# 页面配方

五类页面直接复制结构改内容，不要从空白起手。

## 1. 列表页（商品 / 订单 / 售后）

移动端（用户端）：

```
页面标题（20px）
筛选条：横向 Vant Tabs 或 DropdownMenu，吸顶
卡片列表：每张卡片
  ├ 左图 96x96 圆角 8px
  ├ 右内容：标题 16px 两行截断 / 辅助信息 12px 次级色
  └ 底行：价格 20px 主色左对齐 + 状态徽章右对齐
加载更多（Vant List 的 finished / loading）
```

管理端（Element Plus）：

```
el-card 包裹
  ├ 搜索区：el-form inline，label 右对齐 100px，查询/重置按钮
  ├ 操作区：新增/批量操作按钮组（左），导出（右）
  └ el-table：stripe、border=false、操作列 fixed="right" 宽 160
     列顺序：ID → 主信息 → 状态（el-tag）→ 金额右对齐 → 时间 → 操作
  └ el-pagination：右对齐，layout="total, sizes, prev, pager, next"
```

空态：`el-empty` 或 Vant `Empty`，文案具体（"还没有商品，去发布第一个"）。

## 2. 详情页

```
封面/主图区
标题 + 价格（价格 24px 主色）
关键信息表格：2 列，label 次级色 14px，值 14px 正常色
状态时间线（订单/物流用 Vant Steps 或 el-timeline）
底部固定操作条（移动端）：主操作按钮 + 次操作
```

## 3. 表单页

```
分组标题（16px 加粗，上间距 24px）
字段：label 14px 次级色，输入框 16px 行高 44px（移动端触控区）
必填标记红色 *，错误提示 12px 危险色紧贴字段下方
底部：主按钮通栏（移动端）/ 右对齐按钮组（管理端）
```

管理端用 `el-form` + `rules`，校验文案写业务语（"库存不能为负"而不是"invalid input"）。

## 4. 订单/物流时间线

```
节点：圆点 + 时间（12px 次级色）+ 事件名（14px）+ 地点/说明（12px）
状态色：正常主色或成功色；异常节点用危险色 + 说明
倒序展示：最新在上；同一时间多事件按 eventId 稳定排序
顶部摘要：当前状态徽章 + 运单号 + 预计送达
```

## 5. 空态 / 加载态 / 错误态

| 态 | 移动端 | 管理端 |
|---|---|---|
| 空 | Vant Empty，图标 + 一句引导 + 主按钮 | el-empty + 操作按钮 |
| 加载 | 骨架屏（Vant Skeleton）优先于转圈 | el-skeleton 或表格 loading |
| 错误 | 复用空态样式 + "重试"按钮 + 具体原因 | el-result 的 error 状态 |

## 视图与状态约定

- 购物车数量、登录态放 Pinia；商品价格、库存、订单状态**只信服务端响应**，不做前端推算
- 接口错误统一展示 `message` 字段；`allowedActions` 用于控制按钮可点性，不自行推断
- 页面路由守卫只做体验（未登录跳转），权限以服务端 403 为准
